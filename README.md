# Top 5 Gran Turismo 2

Página web desenvolvida para estudo de HTML e CSS com uma lista pessoal dos cinco carros escolhidos do jogo **Gran Turismo 2**.

Cada carro possui imagem, informações e um breve motivo para estar na lista.

## Tecnologias utilizadas

- HTML
- CSS

## Estrutura do projeto

```text
Top-5-Gran-Turismo-2/
├── imagens/
│   ├── gt40.png
│   ├── mr2.png
│   ├── rs200.png
│   ├── skyliner30.png
│   └── speed12.png
├── index.html
└── style.css
```

## Como visualizar

Abra o arquivo `index.html` em um navegador ou use o botão **Go Live** no VS Code.

## Conteúdo

A página apresenta uma lista ordenada com os cinco carros, incluindo dados como modelo, tração, motor e a razão de cada escolha.
